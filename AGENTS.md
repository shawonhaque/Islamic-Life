# Islamic Life — repo notes for agents

## Build and verify

- `npm run build` runs `scripts/build-quran.mjs` → `scripts/build-brand.mjs` →
  `scripts/build-seo.mjs` → `scripts/build-search-index.mjs` → `vite build`.
- Deploy builds need `GITHUB_PAGES=true` so Vite emits `/Islamic-Life/` asset URLs.
- `npx tsc --noEmit` is the only lint; there is no test runner in this repo.
- To reproduce the deploy locally, serve `dist/` so unknown paths answer
  `404.html` with HTTP 200. `python3 -m http.server` returns 404 instead, which
  makes the app look broken in ways Pages never shows.
- Verify UI changes with Playwright at a 1440px viewport. Headless Chromium
  needs `--use-gl=swiftshader --enable-unsafe-swiftshader` for the Three.js
  views, otherwise the canvas stays blank.

## Deploy

- `.github/workflows/deploy.yml` publishes `dist/` to the `gh-pages` branch on
  every push to `main`. Pages runs in legacy mode, so the branch is the source
  of truth, not the Pages API.
- The workflow copies `dist/index.html` to `dist/404.html` for deep links.

## Things that bite

- `public/` is gitignored. Anything that must ship has to be generated by a
  script during the build (see `scripts/build-brand.mjs`) or imported from
  `src/assets`.
- `server.ts` is not deployed. On the static site every `/api/*` path returns
  the SPA shell with HTTP 200, so use `postJson` from `src/utils/safeFetch.ts`
  for server-only features; it raises `ApiUnavailableError` instead of failing
  on JSON parsing.
- Call `hasBackendApi()` from `src/utils/backendApi.ts` before any raw
  `fetch('/api/...')`. The static build sets `__HAS_BACKEND__` to false so the
  probe is skipped entirely and no 404 is logged.
- Every view is behind `React.lazy` in `App.tsx`, and `EarthGlobe` /
  `QiblaGoogleMap` are lazy at their call sites so `three` and the Maps SDK
  stay out of the entry chunk. Keep new heavy imports lazy.
- Chat and audio transcription therefore have two paths: the express proxy
  when it exists, then `src/utils/geminiBrowser.ts` calling Gemini directly
  with a key the visitor saves in localStorage. Keep both in sync — persona
  text lives in `src/data/aiPersonas.ts` so the server and browser share it.
  Music and video have no browser path; they report a server-only message.
- Gemini model names must exist upstream. The SDK's `Model` union includes
  placeholder names that the live API rejects; the endpoints in `server.ts`
  pin real ones through `resolveModel`.
- Quran data lives in `data/quran/*.json` (tracked, ~140MB) and is converted to
  `public/quran/` by the build script. Never edit `public/quran` by hand.
- Tafsir `apiSlug` values in `src/data/islamicModulesData.ts` must match real
  directories in `spa5k/tafsir_api`. A typo fails silently to bundled text, so
  check a new slug with
  `curl -o /dev/null -w '%{http_code}' https://cdn.jsdelivr.net/gh/spa5k/tafsir_api@main/tafsir/<slug>/1/1.json`.
- `relative` and `fixed` are both `position` utilities, and `rounded-*` values
  are mutually exclusive. Emitting both in a template literal leaves the
  winner to stylesheet order — that is what collapsed the globe fullscreen
  box to zero height. Pick one branch per property.
- `SectionId` in `src/types/islamic.ts` drives routing in `src/App.tsx` and the
  nav lists in `SidebarNav.tsx` / `TopNav.tsx`; add a section in all four.
- Sign-in fails on GitHub Pages with `auth/unauthorized-domain` because
  `firebase-applet-config.json` points at the AI Studio applet project, whose
  authorized domains are only `*.web.app` and `*.run.app`. The fix is config,
  not code: add `shawonhaque.github.io` under Authentication → Settings →
  Authorized domains, or point the build at another project with
  `VITE_FIREBASE_*` (see `.env.example` and the secrets in `deploy.yml`).
  `src/lib/firebase.ts` merges those overrides over the committed JSON.
- The mosque finder (`MosqueFinderPage` → `MosqueMap` + `src/utils/mosqueData.ts`)
  is the only Leaflet surface. Keep `leaflet` and `leaflet.markercluster` lazy:
  the CSS imports alone add ~17 kB, so the page stays behind `React.lazy`.
  Public Overpass mirrors answer 502 "at capacity" for minutes at a time, so
  `fetchMosquesNear` tries three mirrors with a 12 s bound each and falls back
  to the seed list. Do not raise that without a visible loading state.
- Leaflet measures its container on `L.map()`. If the element is not laid out
  yet, the map keeps a zero size and every marker lands off-screen — this is
  what made the map look empty at 390 px while the list still rendered. The
  component now observes its container with `ResizeObserver` and calls
  `invalidateSize()`, and it fits bounds to the markers once.
- A phone viewport at zoom 13 spans only a few kilometres. Never assume the
  default zoom shows markers spread across a city; fit bounds or cluster.

- A Gemini key can list models and still fail generation with 403 when its
  project has no billing. `describeGeminiError` distinguishes that from a
  referrer restriction, so do not assume 403 means the key is browser-blocked.
- `python3 -m http.server` keeps serving whatever it started with. When
  verifying a fresh `dist`, start a server on a new port instead of reusing one.
